# National AI Olympiad 2026 — Foundation Prep Hub

Personal preparation hub for the National AI Olympiad Foundation track (Grades 6–8), maintained for a student preparing for the 2026 Stage 1 exam.

## Important scope

The `*_extracted.txt` files are locally extracted material from the registered Prep Kit. They are retained as reference only and contain OCR/PDF extraction errors. This repository does not attempt to bypass TalentSprint's access controls or redistribute protected PDFs.

The `docs/` material is original, cleaned study guidance based on:

- the public TalentSprint FAQ;
- the topics visible in the locally available extraction;
- standard Python and introductory AI concepts;
- openly available reference links.

## Exam snapshot

According to the official FAQ:

- Stage 1: 50 multiple-choice questions in 90 minutes
- Exam dates: 8–9 August 2026
- Foundation eligibility: school students in Grades 6–8
- Stage 2: a hands-on project for top Stage 1 rankers
- Registered participants receive sample papers on the platform

See [`docs/exam-profile.md`](docs/exam-profile.md) for sources and distinctions between confirmed and inferred information.

## Raw materials

The root-level text files are source extracts, not verified lesson files. Do not use a code example from them without checking it against a Python interpreter. In particular, several examples have damaged punctuation, operators, quotes, brackets, and indentation.

## Adding future material

For each new topic, add:

1. a short explanation in `docs/`;
2. two or three original examples;
3. a small practice set with answers in a separate file;
4. a source note and date if the information came from the web;
5. a progress checkbox in `docs/progress-tracker.md`.

Do not commit platform credentials, screenshots containing personal information, or copies of restricted PDFs.
