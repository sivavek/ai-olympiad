# Raw-materials note

The root-level `*_extracted.txt` files are preserved because they are the locally available source material. They are not treated as authoritative or publication-ready.

## Observed extraction problems

- repeated table-of-contents pages in several AI files;
- truncated headings and words;
- damaged quotes, brackets, operators, and comparison symbols;
- lost Python indentation;
- page headers and branding inserted into the middle of examples;
- some files containing mostly contents pages rather than lesson text.

## Safe workflow for future additions

1. Keep the original extract unchanged.
2. Add a clean original explanation under `docs/`.
3. Re-type examples rather than mechanically trusting OCR.
4. Run examples with Python 3.
5. Record the source and date.
6. Remove personal information before committing notes or screenshots.

The clean notes in this repository are intentionally summaries and original teaching material, not reconstructed copies of the protected Prep Kit.
